# Android-сборка «Игры понятий»

Тестовый APK включает локальную web-сборку и музыку. Интернет нужен для онлайн-комнат и внешних справок. Браузерный iframe на Android не используется. Ориентация — sensorLandscape, клавиатура — adjustResize.

## Сборка
Требуются Node.js 22+, Java 21 и Android SDK 36.
Укажите JAVA_HOME и ANDROID_HOME для своей установки.
Из корня проекта:

```sh
npm ci
npm run android:apk
```

Результат: android/app/build/outputs/apk/debug/app-debug.apk.
Это debug-сборка для установки и тестирования, не релиз Google Play.

Перед сборкой онлайн-версии задайте VITE_SUPABASE_URL и VITE_SUPABASE_ANON_KEY в .env.local. Не используйте service-role ключ. Эти публичные клиентские параметры входят в APK.

## Проверка на телефоне
Проверьте запуск без сети, локальную партию, обучение, перетаскивание и масштабирование, клавиатуру, музыку и загрузку собственного аудио, подключение к онлайн-комнате. Подпись debug позволяет обновлять APK с той же машины без удаления данных.
