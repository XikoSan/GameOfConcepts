# APK-файлы

Готовые тестовые сборки игры складываются в эту папку.

- `GameOfConcepts-vertical-v1.2.17-debug.apk` — актуальная версия: журнал и локальная очередь диагностических событий, подробная расшифровка начисления очков и обновлённый серверный архив на 30 дней. Онлайн-проверка завершения по согласию и локальная проверка отклонения, пересдачи, принятия и завершения пройдены.
- `GameOfConcepts-vertical-v1.2.16-debug.apk` — предыдущая версия: базовый мобильный масштаб в пять клеток по ширине, надёжное подключение к обновлениям онлайн-комнаты и переход к итогам. Сервер обновлён для новой колоды и завершения по согласию.
- `GameOfConcepts-vertical-v1.2.15-debug.apk` — предыдущая версия: камера по количеству и расположению карт, мобильное меню ниже для большого пальца, подробная статистика партии на телефоне.
- `GameOfConcepts-vertical-v1.2.14-debug.apk` — предыдущая версия: мягкая подсветка под словами в цвет игрока, в том числе при перестановке внутри руки.
- `GameOfConcepts-vertical-v1.2.13-debug.apk` — предыдущая версия: колода и пересдача под рукой, фон в цвет игрока, перестановка слов с плавным сдвигом соседей. Справка — удержанием; крупный просмотр и двойное касание убраны, плитка при переносе матовая.
- `GameOfConcepts-vertical-v1.2.12-debug.apk` — предыдущая версия: матовые ярлыки с цветовым акцентом игрока, крупный просмотр при удержании и кнопки, следующие за высотой руки. Справка — двойным касанием.
- `GameOfConcepts-vertical-v1.2.11-debug.apk` — предыдущая версия: слова размещаются по ширине с переносом по длине; высота руки подстраивается под содержимое, выделение не сдвигает соседей.
- `GameOfConcepts-vertical-v1.2.10-debug.apk` — предыдущая версия: компактная рука с лёгким общим фоном и более плотными подложками слов.
- `GameOfConcepts-vertical-v1.2.9-debug.apk` — предыдущая версия: горизонтальные слова с наклоном±4°, разбросом по области руки и увеличением при выборе.
- `GameOfConcepts-vertical-v1.2.8-debug.apk` — предыдущая версия: вертикальные слова с наклоном±4° хаотично распределены по высоте области руки, без общего ряда.
- `GameOfConcepts-vertical-v1.2.7-debug.apk` — предыдущая версия: отдельные слова с лёгкими подложками вместо крупных карт в руке; наклон, увеличение и подсветка выбранного слова, перенос в обычную плитку.
- `GameOfConcepts-vertical-v1.2.6-debug.apk` — предыдущая версия: передняя полностью видимая карта с названием по центру, остальные — вдоль открытого края.
- `GameOfConcepts-vertical-v1.2.5-debug.apk` — предыдущая версия: крупная рука без зазора над картами; названия вдоль открытого края, у выбранной карты по центру; длинные слова уменьшаются шрифтом.
- `GameOfConcepts-vertical-v1.2.4-debug.apk` — предыдущая версия: более высокие карты в руке и плавное уменьшение до размера клетки при переносе на поле.
- `GameOfConcepts-vertical-v1.2.3-debug.apk` — предыдущая версия: увеличенные карты, справка по удержанию, текстовая пересдача, новая компоновка игроков и независимое окно обновлений.
- `GameOfConcepts-vertical-v1.2.2-debug.apk` — предыдущая версия: возврат карты в веер, новое расположение кнопок и читаемые обновления в меню.
- `GameOfConcepts-vertical-v1.2.1-debug.apk` — предыдущая версия с карточной рукой-веером.
- `GameOfConcepts-vertical-v1.2.0-debug.apk` — предыдущая вертикальная версия.

Это debug-сборка для установки и проверки на телефоне. Иконка приложения включена в APK.
