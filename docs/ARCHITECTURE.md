# Карта проекта

Рекомендуемый порядок чтения: `game-rules.md` → `src/types.ts` → `src/gameActions.ts` → `src/game.ts` → `src/scoring/` → контроллеры → интерфейс.

## Как проходит ход

Перетаскивание → размещение pending-карты → выбор семантических отношений → обоснование и голосование → принятие или возврат карты. Только принятие фиксирует связи, очки и запись лога. Общая колода пополняет руку; отклонение не расходует её.

В онлайне текущий ход вычисляется через `turn_order[current_turn_index]`, затем playerId переводится в seatIndex. Индекс массива игроков не заменяет место. Realtime доставляет сохранённый снимок, а не запускает отдельную игровую логику. Версия строки обнаруживает гонки; она не заменяет авторизацию.

## Практика изменений

После изменений: `node tests/run.mjs`, `npm run build`, `npm run lint`. Android использует собранный dist: `npm run android:sync`, затем Gradle. Одного изменения веб-кода для установленного APK недостаточно.

Меню и обучение не перерабатываются в рамках подготовки первого релиза. Новые направления колод пока обсуждаются: социально-политическое, философское, психологическое, экономическое. Состав не утверждён.

Комментарии в коде объясняют границы ответственности и ограничения; простые элементы JSX не комментируются построчно, чтобы важные замечания оставались заметными.
