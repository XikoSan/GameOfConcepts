# Разработка и сборка

Проект написан на React и TypeScript, веб-сборку выполняет Vite. Android-приложение использует Capacitor и включает собранную веб-версию. Онлайн-комнаты работают через Supabase.

## Запуск локально

Требуется Node.js 22 или новее. Из корня репозитория:

```sh
npm ci
npm run dev
```

Для онлайн-комнат задайте `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` в `.env.local`. Используйте только публичный клиентский ключ: значения `VITE_*` входят в веб-сборку и APK. Локальная партия и обучение не требуют настройки онлайн-комнат.

## Проверки

```sh
npm test
npm run build
npm run lint
```

После сборки готовые веб-файлы находятся в `dist/`. Команда `npm run preview` запускает их для локальной проверки.

## Android

Требования, сборка тестового APK и проверка на телефоне описаны в [android/README.md](../android/README.md). Изменения веб-кода попадут в APK только после новой сборки и синхронизации Capacitor.
