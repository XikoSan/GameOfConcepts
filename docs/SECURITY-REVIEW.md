# Проверка перед 1.0.0

Проверка исходного кода и рабочих зависимостей. Это не полноценный пентест и не подтверждение отсутствия уязвимостей. Разрушительные запросы к чужим/активным партиям не выполнялись.

## Существенные находки

1. **Высокая: клиентская идентичность и изменение всей комнаты.** `usePlayerIdentity.ts` хранит playerId в localStorage; `roomService.ts` записывает весь game_state напрямую. Проверка хозяина перед delete выполняется в клиенте. При доступных anon-записях обход интерфейса позволяет менять состояние/удалять комнаты. SQL в репозитории не задаёт защитные RLS-политики для rooms; фактические права production требуют отдельной проверки. Нужны Supabase Auth, членство в комнате по auth.uid(), RLS и серверная обработка действий. Нельзя просто включить RLS без миграции клиентов: онлайн перестанет работать.
2. **Высокая для честности игры: чужие руки передаются клиенту.** `rooms.game_state` содержит все руки, UI скрывает их только визуально. Нужны публичный снимок поля и приватные руки с доступом по участнику; запрет SELECT всей строки с секретной частью.
3. **Средняя: загрязнение исследовательских данных и расход ресурсов.** `record_local_relations` доступен без аутентификации. Дедупликация не препятствует выдуманным уникальным ID. Нужны ограничения частоты/квоты и отбор данных. Онлайн JSON тоже формируется клиентом, поэтому принятая связь не гарантирует истинность.
4. **Средняя: отладочные дампы.** Логи содержат никнеймы, полное состояние и руки. Вызовы console.log/debug ограничены import.meta.env.DEV; в релизной сборке отладочные дампы исключены. Сообщения об ошибках остаются. Не прикладывать полное состояние к баг-репортам автоматически.

## Выполнено и проверено

- npm audit --omit=dev: 0 известных уязвимостей. Полный audit первоначально показал 9; совместимое npm audit fix обновило 11 пакетов. Остались 3 moderate-находки одной цепочки uuid → xcode → @capacitor/cli (инструменты сборки iOS). Принудительное понижение CLI не выполнялось.
- Проверены 317 отслеживаемых путей; среди текстовых файлов не найдены сигнатуры приватных ключей, распространённых приватных токенов и service-role JWT. .env и ключи подписи не обнаружены в списке Git. Проверка эвристическая, вся история Git не сканировалась.
- Дополнен .gitignore для env-файлов и ключей подписи.
- Публичный Supabase anon key предназначен для клиента; service-role ключ и почтовые ключи нельзя добавлять в VITE_*.
- По решению владельца обратная связь пока только текстовая: описание ограничено 4000 символами, текст кодируется перед передачей в mailto. Файлы не загружаются.
