# Завершение партии без одиночного доигрывания

Дата: 5 ноября 2026 года. Статус: принято пользователем.

Обновление 13 ноября 2026: положение о немедленном завершении при единственной непустой руке заменено решением [об одном завершающем ходе](2026-11-13-final-turn.md). Остальные положения о пасах действуют с этим исключением.

Основание: поручение реализовать окончание партии из аудита релизной готовности и уточнение пользователя: игрок с подходящими картами не должен играть один, пока остальные смотрят. На вопрос о немедленном завершении после пасов всех остальных, включая один пас в партии вдвоём, пользователь ответил: «Да, заканчивать сразу».

После исчерпания колоды последовательность из N−1 пасов заканчивает партию, где N — число участников. Пустая рука считается автоматическим пасом. Принятый ход сбрасывает последовательность. Отмена или отклонение хода не являются пасом. Если карты остались только у одного игрока или закончились у всех, партия сразу завершается. Пустая рука не лишает участника права голосовать до завершения.

Досрочное завершение требует единогласия. Пока в колоде есть карты, активный игрок может предложить завершение до размещения карты. Один отказ возвращает партию к тому же ходу. Победитель определяется по наибольшему счёту. При равенстве максимумов объявляется ничья между лидерами.

Полный действующий текст находится в [правилах игры](../../game-rules.md). Подсчёт очков, типы связей и порядок принятия обычного хода не меняются.
