# Новые 100 слов-кандидатов: характеристики, противопоставления и разновидности

Исследование E03 · 28 сентября 2026 года.

Вторая самостоятельная подборка: все 100 названий отличаются от E02. Из десяти тематических категорий сохранены шесть и заменены четыре (40%). В каждой категории десять слов. Сохранение категории не означает сохранение её слов.

Рабочий возрастной ориентир остаётся 7–12 лет. Подбор и предполагаемые связи — аналитические гипотезы; понятность для детей и распределение пар ещё не проверены. Категории служат организации списка, а не являются картами. Конкретные бытовые предметы не включены; геометрические фигуры рассматриваются как формы.

Приоритет: характеристика, противопоставление, разновидность. Не требуется, чтобы каждое слово участвовало во всех трёх отношениях. Предпочтения не превращены в искусственные квоты связей. Расчёт вероятности руки по-прежнему отложен.

## Примеры предполагаемых отношений внутри нового списка

| Отношение | Пример | Условие / пояснение |
|---|---|---|
| Характеристика | Речь → волнение | Волнение — состояние говорящего, поэтому такую пару не принимаем автоматически как характеристику речи. |
| Характеристика | Лепка → аккуратность | Выполнение лепки может быть аккуратным. Характеризуется действие, а не материал. |
| Характеристика | Прыжок → высота | Высота характеризует конкретный прыжок. |
| Характеристика | Рассказ → длина | Длина текста; переносное употребление требует отдельного решения о допустимости. |
| Противопоставление | Смелость ↔ трусость | Противопоставленные качества поведения. |
| Противопоставление | Увеличение ↔ уменьшение | Противоположные изменения по одному параметру. |
| Противопоставление | Мягкость ↔ твёрдость | При сравнении одной и той же характеристики материала. |
| Разновидность | Квадрат → форма | Квадрат — геометрическая форма. |
| Разновидность | Восторг → эмоция | Восторг — сильная положительная эмоция. |
| Разновидность | Шёпот → речь | Шёпот — способ речевого высказывания. |

## На что обратить внимание при следующей проверке

- Отсутствие повторов названий не означает отсутствие смысловых дублей: «Печаль» близка к прежней «Грусти». При объединении пулов такие слова нужно пересмотреть.
- «Множество», «Неравенство», «Прозрачность», «Небрежность» требуют особенно внимательной проверки понятности. Возраст усвоения здесь не установлен.
- «Трусость», «Жадность», «Жестокость» описывают поведение; в игре их не следует использовать как оценку личности участника.
- «Шёпот — крик» различаются громкостью, но это ещё не делает их строгими противоположностями. Аналогично «Сладость — горечь»: различие вкусов само по себе не доказывает противоположность.
- Для «Разновидности» нужна конструкция «A — это вид B», а не просто общая тема. Например, отдельный прыжок не является видом спорта.
- Для «Характеристики» фиксируем, что именно характеризуется, и исключаем подмену свойства действием, причиной или частью.
- Следующий этап — разметка пар и подсчёт распределения. Числа связей не переносятся из предыдущего списка.
