# Простая колода: 100 слов-кандидатов

Исследование E02 · Версия 0.1 · 28 сентября 2026 года.

Рабочий ориентир: 7–12 лет, с приоритетной проверкой понятности для 7–9-летних. Это проектная гипотеза, не подтверждённая возрастная маркировка. Доступность для 3–6-летних не установлена.

Источник всех кандидатов — экспертный подбор ассистента. Это новый поисковый пул, не расширение утверждённой колоды и не перечень эмпирически проверенных слов. Число 100 задано пользователем. Десять тематических групп по десять слов служат организации поиска, а не задают квоты итоговой колоды.

Текущий этап: поиск и фиксация значений. Конкретные предметы не включены. Число связей, распределение типов, понимание слов и качество игровых справок ещё не проверены. Расчёт вероятности руки отложен согласно обсуждению. Сначала фиксируются объяснения пар, затем из них выделяются отношения. Прежние шесть типов не используются как обязательный фильтр списка.

- C02: экспертно отобраны непредметные слова о состояниях, действиях, отношениях и наблюдаемых свойствах; соответствие аудитории требует проверки.
- C03–C05: недостаточно данных; участников и проверенных справок нет.
- C06–C10: недостаточно данных; связи, дубли и вклад в набор исследуются следующим этапом.
- Реестр наблюдений пуст. Сходные понятия сохранены намеренно для сравнения, а не объявлены независимыми игровыми возможностями.

## Следующий этап

1. Для пар записывать естественное объяснение, не подгоняя под готовый тип.
2. Отмечать прямое объяснение, контекстное объяснение и отсутствие найденного обоснования.
3. Разделять возникновение, усиление, ослабление, необходимость, разновидность и другие обнаруженные отношения; решение об объединении принимать после разметки.
4. Проверить близкие кандидаты: интерес/любопытство; помощь/поддержка/забота; ложь/обман; прощение/примирение; успех/победа.
5. Сохранять пары, не укладывающиеся в предложенные отношения, для пересмотра самой системы.

Изменений действующего каталога игры не внесено.
