# Проверенные добавления

Прежняя классификация центров сохранена. Пары — авторские гипотезы; отсутствие аннотации не является доказательством отсутствия связи.

| Кандидат | Прямые партнёры среди 54 + 7 кандидатов | После повторного отсева |
|---|---|---|
| бессилие | истощение, разбитость | включён |
| воодушевление | приподнятость, уныние | включён |
| дискомфорт | комфорт, неудовольствие | менее двух партнёров после отсева |
| истощение | бессилие, усталость | включён |
| комфорт | дискомфорт | менее двух партнёров после отсева |
| подавленность | приподнятость, уныние | включён |
| приподнятость | воодушевление, подавленность | включён |

## Журнал решений

| Пара | Оценка | Объяснение |
|---|---:|---|
| приподнятость — подавленность | 2 | Эмоциональный подъём и упадок противопоставлены по направлению общего эмоционального тонуса. |
| приподнятость — воодушевление | 2 | Воодушевление включает эмоциональный подъём — приподнятость; обратное не обязательно. |
| воодушевление — уныние | 2 | Воодушевлённый и унылый настрой противопоставлены по наличию душевного подъёма и побуждения действовать. |
| подавленность — уныние | 2 | Уныние включает подавленное настроение; это рабочее различение общего сниженного фона и унылого отношения к происходящему, а не две независимые базовые эмоции. |
| приподнятость — радость | 1 | Радость может сопровождаться приподнятым настроением; причинный переход и тождество не обязательны. |
| приподнятость — бодрость | 1 | Душевный подъём и телесная бодрость различимы; перенос слова бодрость в смысл настроения изменил бы ранее выбранное значение. |
| подавленность — вялость | 1 | Вялость может сопровождать подавленность, но эта связь не включается в строгий граф без дополнительного обоснования. |
| воодушевление — бодрость | 1 | Душевный подъём может сочетаться с ощущением сил; оба переживания не определяют друг друга. |
| бессилие — истощение | 2 | Истощение сил включает бессилие; здесь бессилие рассматривается именно как нехватка сил, а не неспособность решить задачу. |
| бессилие — разбитость | 2 | Разбитое самочувствие включает ощущение недостатка сил; телесный смысл фиксирован для этой пары. |
| истощение — усталость | 2 | В смысле крайнего утомления истощение является выраженной формой усталости; это не медицинская классификация причин истощения. |
| бессилие — отчаяние | 1 | Отчаяние может возникнуть при осознании бессилия, но нуждается в ситуации и оценке человеком. |
| истощение — страдание | 1 | Истощение может сопровождаться страданием, но не задаёт конкретное эмоциональное переживание автоматически. |
| комфорт — дискомфорт | 2 | Приятное удобное и неприятное неудобное самочувствие противопоставлены по одному измерению. |
| дискомфорт — неудовольствие | 2 | В выбранном значении неприятного самочувствия дискомфорт включает неудовольствие. |
| комфорт — удовольствие | 1 | Комфорт может приносить удовольствие, но это не достаточное основание назвать его разновидностью удовольствия. |
| комфорт — спокойствие | 1 | Можно испытывать тревогу в комфортных условиях; прямая связь не установлена. |
| дискомфорт — усталость | 1 | Усталость может быть неприятна, но не всякая усталость означает дискомфорт. |
| апатия — вялость | 0 | В словарях вялость встречается в синонимическом ряду апатии; не считать эту близость самостоятельным мостом между темами. |
| апатия — безразличие | 0 | В выбранном общем значении сильный смысловой повтор уже имеющегося безразличия. |
| умиротворение — спокойствие | 0 | Для этого состава недостаточно различимы; не добавлять ещё одно обозначение внутреннего покоя. |
| расслабление — истома | 1 | Оставлена прежняя оценка: приятная усталость может сопровождаться расслаблением, но не требует его. |
| усталость — вздох | 1 | Вздох может выражать усталость, но найденной опоры недостаточно для повышения до прямой связи; не добавляем ради обхода истомы. |
