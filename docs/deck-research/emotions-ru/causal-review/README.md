# Повторная проверка причины

Пользователь указал на естественную связь «радость — причина улыбки». Прежний ноль у причинности отражал выбранный способ классификации аннотаций, а не отсутствие причинных объяснений. Вывод о необходимости отдельного проявления был преждевременным.

## Критерий

**Первое понятие может вызвать второе либо побудить к нему. Игрок объясняет, как.** Причина не обязана всегда приводить к следствию и не обязана быть единственной. Обратный вывод недопустим: улыбка сама по себе не доказывает радость. Простого совместного появления двух явлений недостаточно.

## Результат

Из 35 ранее выделенных пар проявления для 31 записано самостоятельное причинное объяснение, три требуют конкретизации отношения, одна остаётся спорной. Это оценка правдоподобия для игры, а не 31 научно установленная причинная зависимость. Проверены 35 известных пар, не все возможные пары колоды и не все возможные причинные ходы.

Примеры: Радость → Улыбка; Страх → Дрожь; Горе → Плач; Облегчение → Вздох; Усталость → Вялость; Любовь → Объятие (мотив действия). Направление совпадает с классической причиной: причина → следствие. Прежнее предложение направления проявление → чувство здесь не применяется.

Старые пять типов предварительно покрывали 67 из 106 пар. Вместе с 31 причинным объяснением получается 98 из 106, но это арифметическое покрытие по гипотезам, не подтверждение правильности всех пар: старые оговорки к виду, свойству и составляющим сохраняются. Количество внутренних пар не увеличивается; меняется возможное обоснование уже существующих пар.

## Альтернативы названию

- **Выражение** — наиболее понятная замена для улыбки, смеха, ласки; менее естественна для вялости от усталости.
- **Признак** — обозначает, по чему можно предположить состояние; не равно причине и не означает однозначную диагностику.
- **Отражение** — допускает больше толкований и хуже задаёт проверяемое правило.

Рекомендация: пока не вводить отдельный шестой тип. Сохранить причинность; для интерфейса можно предложить название «Вызывает», но это ещё не принятое изменение. Уточнение «может вызвать» соответствует пользовательскому примеру. Если после испытания останутся выражения без убедительного причинного объяснения, рассмотреть для них отдельное «Выражение».
