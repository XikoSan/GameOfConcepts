# Проверка второй пятёрки центральных понятий

Это исследовательское продолжение, без изменений игры. Все результаты — авторские смысловые гипотезы, не данные опроса и не научные нормы.

## Единая база сравнения

Из исходных 310 исключены пять прежних центров и «желание», которое теперь само является центром. Оставшиеся **304 слова** проверяются против каждого из пяти новых центров: **1 520 ячеек**. Четыре новых слова не добавлены как партнёры в исходный словник. Первая пятёрка пересчитана на той же базе. Синонимические группы сохранены из предыдущего аудита.

Проверяются прямые формы/содержание и выражения. Возможные причины, объекты желания, свойства выражения и другие отношения не подмешиваются в основной счётчик. Поэтому «я могу выразить любое чувство» не даёт «выражению» автоматически 167 партнёров. Ноль означает невключение по ограниченному критерию, не невозможность любой связи.

## Вывод

- **Состояние** — широкий центр, но его широта сама по себе не означает большой новый охват: многое уже входит в переживание. Может быть альтернативой или дополнительной общей картой.
- **Отношение** выделяет направленность к людям, себе и объектам: любовь, доверие, уважение, неприязнь. Полезный отдельный ракурс, даже при пересечении с чувством.
- **Реакция** выделяет ответ на происходящее: испуг, удивление, возмущение. Пересекается с эмоцией, но задаёт иной вопрос.
- **Выражение** — центр внешних проявлений, а не внутреннего содержания. Новых слов по сравнению с первой пятёркой может почти не быть: первая пятёрка уже считала выражения. Это не делает роль слова бесполезной.
- **Желание** даёт небольшой, но отдельный мотивационный участок. Не расширять его автоматически за счёт всех желаемых объектов или приятных эмоций.

Предложение: сохранить все десять как исследовательских кандидатов, не как окончательную центральную колоду. Для различимых стартов прежде всего рассмотреть отношение, реакцию и выражение. Состояние сравнить с переживанием; желание проверить вместе с дополнительным словником мотивации. Число новых слов — диагностическая метрика, не новый обязательный критерий пользователя.

## Спорные места

«Состояние» могло бы включать почти любое переживание при широком употреблении. Здесь устойчивые отношения и качества вынесены в пограничные. «Жажда» засчитана для желания только в переносном значении из исходного словника; телесная жажда не подменяет его. «Признание» для отношения — признание заслуг, а не признание в любви. «Выражение» зафиксировано как внешняя форма; признаки вроде искренности и содержание вроде радости отмечены пограничными для данного ограниченного счёта.

## Источники и происхождение чисел

Значения уточнялись по доступным индексированным выдержкам словарей Грамоты. Источники не подтверждают наши индивидуальные пары или цифры.

- [Желание](https://gramota.ru/poisk?mode=all&query=желание): внутреннее стремление к чему-либо.
- [Выражение](https://gramota.ru/poisk?mode=slovari&query=Выражение): передача содержания словами или другими средствами.
- [Ответ](https://gramota.ru/poisk?mode=all&query=Ответ): ответное действие или отклик; косвенное основание для значения реакции.

[Состояние — метасловарь Грамоты](https://gramota.ru/meta/sostoyanie) описывает внутреннее самочувствие и расположение духа. Для отношения здесь явно задано эмоционально-оценочное рабочее значение; оно не выдаётся за дословное словарное определение.
