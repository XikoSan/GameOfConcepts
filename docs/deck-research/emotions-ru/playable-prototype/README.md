# Рабочий состав «Эмоции и чувства»

## Результат

Из 211 понятий с прямым покрытием хотя бы одного из восьми центров выделена группа из **57 карт и 80 уникальных прямых пар**. У каждой карты минимум два партнёра внутри этой группы; среднее — 2.81. Это результат текущей экспертной разметки, не готовая сбалансированная колода и не глобальный рейтинг всех возможных связей.

Центры сохранены по выбору пользователя: Переживание, Настроение, Ощущение, Состояние, Реакция, Отношение, Чувство, Эмоция.

## Покрытие центров

| Центр | Подходящих карт из 57 | Риск пустой стартовой руки |
|---|---:|---:|
| Переживание | 46 | 0.01% |
| Настроение | 10 | 36.63% |
| Ощущение | 6 | 56.10% |
| Состояние | 47 | 0.01% |
| Реакция | 30 | 1.93% |
| Отношение | 13 | 25.94% |
| Чувство | 47 | 0.01% |
| Эмоция | 35 | 0.63% |

Риск = C(N − K, 5) / C(N, 5), где N — размер игровой колоды, K — число размеченных прямых партнёров конкретного центра. Модель: на поле один центр, рука из пяти случайных разных карт, до пересдачи. Это вероятность отсутствия размеченного прямого совпадения, а не измеренная вероятность невозможного хода. Контекстные объяснения не учитываются. Для развитого поля нужна совокупность уникальных партнёров всех доступных карт, а не сумма их степеней.

## Что мешает считать состав готовым

- «Ощущение» ранее было ограничено телесным значением. Его шесть партнёров: напряжение, расслабление, бодрость, усталость, вялость, разбитость. Расширять смысл незаметно ради хороших чисел нельзя.
- Бодрость, усталость, вялость и разбитость образуют отдельную группу прямых связей. С остальными картами они соединяются только через размеченные контекстные отношения. Общие нейтральные центры в этом графе не учитываются.
- Выражения чувств (смех, плач, слёзы и другие) часто становятся связующими картами. Это полезно для связности, но расширяет тему за пределы названий собственно эмоций.
- Прежние условные смысловые дубли объединены. Остались близкие понятия вроде покоя и спокойствия, враждебности и ненависти: их различимость требует отдельной проверки.
- Разметка неполная и неравномерная. Неразмеченная пара не означает невозможную связь; исключённое слово не означает плохую карту.

## Как выполнен отбор

1. Собраны все представители слов, имеющие оценку 2 хотя бы для одного выбранного центра. Короткий ручной список из selection.json не ограничивает итоговый пул.
2. Взяты прямые пары из прежнего аудита и дополнительные явные смысловые гипотезы из selection.json. Близость значения сама по себе не засчитывается как игровая пара. Несколько объяснений одной пары не увеличивают число партнёров.
3. Последовательно исключены карты с менее чем двумя партнёрами; после каждого исключения степени пересчитаны. Получена максимальная сохраняющаяся группа с минимум двумя партнёрами по текущему графу. Это порог пригодности, а не оптимизация качества.
4. Посчитаны покрытия центров, компоненты связности и вероятности. Типы исследовательских отношений не являются утверждёнными типами связей в игре.

## Проверка уменьшения размера

Детерминированный жадный расчёт проверяет удаление одной карты с последующим отсевом карт с менее чем двумя партнёрами. Он выбирает вариант с меньшим максимальным риском пустой руки среди центров, затем с большей средней степенью. Это диагностическая траектория, не доказанный оптимум. Минимум 20 карт — техническая граница сравнения, не требование к колоде.

## Следующее действие

Сохранить 57 слов как рабочий пул. Проверить недостающие прямые пары у карт самочувствия, настроений и отношений с остальным пулом; записывать конкретное короткое объяснение каждой пары и не повышать оценку только ради связности. Затем проверить смысловые дубли и повторить расчёт. Все восемь центров пока оставить. Итоговый размер выбирать после этой проверки.

Проверки подтверждают расчёт, но не семантическую правильность гипотез. Исходные данные: ../words.json, ../pair-audit/, ../central-concepts/, ../central-concepts-v2/, selection.json. Код и правила игры не изменены.
