# Повторная проверка состава «Эмоции и чувства»

Проверено 35 выбранных пар и пять решений о резерве близких либо стилистически избыточных карт. Это целевой редакторский проход по самочувствию, настроениям и отношениям, а не полный аудит всех сочетаний. Неопровергнутые старые аннотации сохранены, поэтому результат всё ещё зависит от их качества.

## Решения о близких понятиях

- **покой**: Оставлено спокойствие: повтор внутреннего покоя.
- **доброжелательность**: Оставлено дружелюбие: разведение слишком тонкое для первого состава.
- **нега**: Книжное сочетание удовольствия и покоя; в резерв без передачи связей.
- **жалость**: В этом составе выбран представитель сострадание; не универсальное тождество слов.
- **сочувствие**: В этом составе выбран представитель сострадание; более широкое слово остаётся в резерве.

Сохранены различия: вялость — низкая активность, усталость — утомление, разбитость — выраженное плохое самочувствие; неприязнь — отрицательное отношение, ненависть — его сильная форма; испуг — внезапная реакция, страх — более общее переживание. Это редакторская фиксация смыслов, не доказательство полной лексической независимости. Интенсивность сама по себе не причина удалять карту, но такие группы остаются кандидатами на дальнейшее сокращение.

## Журнал проверки пар

2 — прямая объяснимая связь в фиксированном смысле; 1 — нужен ситуативный контекст; 0 — не считать пару из-за смыслового дублирования. Это не шкала эмпирической достоверности. Возможное выражение чувства допускается на уровне 2 без утверждения, что оно обязательно. Общая причина или простое совместное появление остаются уровнем 1.

## Главная чувствительность результата

Связность телесной группы появилась через истому: усталость → истома → удовольствие. Пара «истома — удовольствие» засчитана только в заранее выбранном значении приятной усталости. Это явное ограничение смысла, а не универсальное толкование. Такая цепочка показывает достижимость в недиректированном графе пар; она НЕ является примером бонусного смыслового пути по правилам игры. Единственная связующая карта делает эту группу уязвимой.
