# Аудит классических типов связей

Источник правил: game-rules.md, раздел 5. Анализируется утверждённый рабочий состав: 57 игральных и 5 нейтральных карт. Правила игры и состав не изменены.

## Вывод

Набор частично подходит. Вид и противоположность востребованы; часть применима как составляющая переживания; свойство встречается редко. Главный пробел — проявление: выражение эмоции жестом, голосом или телесным признаком. Причинность остаётся возможной, но её нельзя выводить автоматически из выражения или совместного появления.

Для каждой пары выбрано одно основное отношение, чтобы суммы не раздувались. Это редакторская раскладка, не запрет нескольких убедительных объяснений. В старые пять типов предварительно укладываются 67 из 106 пар (63,2%); 35 требуют отдельного проявления, ещё четыре имеют иную природу или сомнительное исходное обоснование. Две пары вида дополнительно отмечены как спорные. Число 67 не является числом независимо подтверждённых пар.

Ноль у причины означает, что в уже принятом строгом списке нет пары с причинностью как основным обоснованием. Это НЕ означает отсутствие возможных причинных ходов. Исходный аудит намеренно оставлял многие причинные предположения на контекстном уровне; по этому графу нельзя сравнивать реальную частоту типов в игре.

## Нейтральные карты

Отдельно учтены 198 известных пар с пятью нейтральными: 160 размечены как форма/содержание и 38 — как выражение. Первые являются кандидатами на вид или составляющую, но прежняя метка сама по себе не доказывает конкретный тип. Вторые подтверждают, что отсутствие типа проявления влияет и на стартовые ходы. Десять ещё не проверенных пар перенесённых настроения/отношения с центрами сюда не включены.

## Рекомендуемый набор для первой проверки

| Тип | Короткое правило | Направление и пример |
|---|---|---|
| Вид | Первое — разновидность второго | Ужас → Страх |
| Составляющая (уточнение «Части») | Первое входит в состав второго | Напряжение → Тревога |
| Причина | Первое может вызвать второе; игрок объясняет механизм и ситуацию | Усталость → Раздражение, контекстный пример, не добавленный в строгий граф |
| Свойство | Первое характеризует второе | Безутешность → Горе; редкая и спорная трактовка |
| Противопоставление | Общий признак, по которому понятия противопоставлены | Бодрость ↔ Усталость |
| Проявление — новый тип | Первое может выражать или проявлять второе | Улыбка → Радость; Дрожь → Страх |

Для первой проверки предложены шесть типов: сохраняются возможности старых пяти и добавляется недостающее проявление. Название «Часть» можно уточнить в подсказке без изменения направления. Направление нового проявления выбрано от выражения к выражаемому; это отдельная предлагаемая договорённость, ещё не правило игры. Направления существующих типов не разворачиваются. Симметричным остаётся только противопоставление.

Не стоит подгонять улыбку под свойство радости, а страх автоматически объявлять причиной любого крика. Проявление описывает выражение, причина — возникновение. Один пример может допускать оба объяснения, но они не тождественны. Наличие проявления не является диагнозом или однозначным признаком чувства.

## Остаточные случаи

- Горе — Сострадание и Страдание — Сострадание: объект чужого переживания. Это не автоматически часть или вид. Причинное объяснение возможно только отдельной проверкой, пока его не засчитываем.
- Напряжение — Облегчение: ослабление состояния. Можно в будущем проверить тип «Ослабляет», но одной пары недостаточно для обязательного отдельного типа.
- Безнадёжность — Отчаяние: прежнее объяснение указывает на общую утрату надежды, а не доказывает включение. Нужен пересмотр самой пары.

## Что делать дальше

Рекомендация: проверить шеститипный набор на объяснениях пар, затем пересчитать граф с учётом только подходящих типов. Нельзя обещать сохранить прежние 106 допустимых пар и минимум два партнёра: текущая колода отбиралась до фиксации типов. Например, безнадёжность может потерять второго партнёра при исключении спорной пары с отчаянием. Не добавлять типы только для спасения конкретной карты.
