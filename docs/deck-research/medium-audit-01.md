# Средняя колода: первичный аудит M01

Дата: 28 сентября 2026. Источники: `src/data/cardCatalog.ts`, `src/data/deckDefinitions.ts`, `game-rules.md`, протокол `selection-protocol.md`.

Это кабинетная оценка ассистента. Проверены состав и названия всех 40 карт; ниже — диагностические примеры отношений, а не полный перебор 780 неупорядоченных пар. Число возможных связей каждой карты пока не измерено. Игровые сводки и понимание игроками не проверены. Возраст для средней колоды не установлен; детский профиль предыдущей колоды не переносится. Код игры не изменён.

## 1. Проверяемые факты

- 40 активных карт; повторов ID и названий внутри состава нет.
- Состав выбирается по difficulty=medium. Отдельного каталога, профиля связей и нейтрального набора нет.
- Используются Вид, Часть, Причина, Свойство, Противоположность; первые четыре направленные.
- У всех 40 определений отсутствует description: выбранное значение не закреплено в каталоге.
- Стартовые карты: Человек, Общество, Мир, Система, Изменение. Общество одновременно есть в игровой колоде. Это не ошибка ID (они разные), но одинаковые названия нельзя размещать рядом по действующим правилам.
- Не следует оценивать среднюю колоду вместе с картами простой или сложной: например, привычные пары с «Человеком» доступны только при соответствующем нейтральном старте.

## 3. Диагностические пары

Это намеренно выбранные примеры для выявления проблем правил. Частоты по ним нельзя выдавать за распределение всех связей колоды.

| Пара | Возможное объяснение | Оценка в текущих пяти типах |
|---|---|---|
| Семья → Общество | Семья является социальной частью общества | Часть: прямая при социальном понимании целого |
| Закон → Норма | Правовой закон выражает правовые нормы | Вид: спорно, закон как акт может содержать несколько норм; не считать автоматически |
| Норма → Правило | Социальная норма задаёт правило поведения | Вид: возможно после фиксации обоих значений |
| Искусство → Культура | Искусство — составляющая культуры | Часть: прямая при широком значении культуры |
| Традиция → Культура | Традиции входят в культуру | Часть: прямая при том же значении культуры |
| Исследование → Наука | Научное исследование входит в научную деятельность | Часть: контекстная, не всякое исследование научное |
| Образование → Знание | Обучение приводит к получению знаний | Причина: контекстная; результат не гарантирован |
| Конкуренция → Конфликт | Борьба за один ресурс приводит к столкновению интересов | Причина: контекстная; мирная конкуренция — контрпример |
| Репутация → Доверие | Хорошая репутация способствует доверию | Причина: контекстная; слово «хорошая» добавляет существенное условие |
| Язык → Общение | Язык используется для общения | Естественное отношение средства; само по себе не обосновывает Часть или Причину |
| Деньги → Торговля | Деньги используются при оплате | Средство; бартер показывает, почему причинность не универсальна |
| Закон → Торговля | Закон устанавливает правила торговли | Регулирует: естественное отношение, отдельного типа сейчас нет |
| Правило → Сотрудничество | Правило распределяет действия участников | Регулирует: требует контекста конкретного правила |
| Память → Образование | Запоминание помогает учиться | Помогает: не тождественно Причине образования |
| Знание → Решение | Знания помогают выбрать действие | Помогает: контекстная связь; знания не гарантируют решение |
| Ответственность → Команда | Команда ответственно выполняет работу | Свойство: возможно лишь при смене «обязанности» на качество; нельзя незаметно смешивать |
| Конкуренция ↔ Сотрудничество | Соперничать или действовать совместно ради результата | Противоположность: контекстная; совместимы на разных уровнях |
| Религия ↔ Наука | Два разных способа обращения с вопросами о мире | Различие не доказывает противоположность; в основной граф не включать без отдельного основания |
| Риск ↔ Безопасность | Сравнение условий по защищённости от одной угрозы | Противоположность: спорная; наличие риска не означает отсутствие безопасности |
| Традиция ↔ Изобретение | Сохранение практики и появление нового решения | Не прямая противоположность; изобретение может стать традиционным |

## 4. Главные закономерности

1. **Социальная направленность.** Это набор об обществе, институтах, познании, экономике и взаимодействии, а не просто универсальные слова средней сложности. Возможное рабочее название — «Общество и деятельность», но переименование требует отдельного решения.
2. **Много понятий одного уровня.** В колоде Наука, Религия, Искусство, Образование; меньше конкретных разновидностей и деталей. Возможности Вид и Часть следует проверить отдельно, а не предполагать по знакомству слов.
3. **Мало явно названных качеств и противоположностей.** Для Свойства игрок часто начинает описывать людей и коллективы словами, которые обозначают отношения или обязанности. Для Противоположности возникает риск засчитать тематическое различие. Равномерность типов не является критерием; проблема — точность обоснования.
4. **Широкая причинность способна скрыть слабость набора.** «X влияет на Y» не равно «X вызывает Y». В обществе условия и посредники особенно важны. Считать число соседей без их фиксации преждевременно.
5. **Неоднозначность создаёт ложную связность.** Организация как коллектив и организация как процесс могут дать разные графы. Сумма их соседей завышает пригодность одной карты при едином значении.
6. **Часть слабости может принадлежать правилам, а не словам.** Язык, Деньги, Правило хорошо сочетаются с темой, но естественно требуют отношений средства и регулирования. Удалять их только за малое число текущих типов рано.

## 5. Что делать дальше

1. Зафиксировать по одному значению всех карт. В первую очередь: Организация, Решение, Закон, Норма, Ответственность, Рынок, Технология, Доказательство.
2. Разметить все 780 пар с объяснением, направлением и статусом. Необоснованная и непроверенная пара — разные статусы. Не объявлять граф полным перечнем возможных игровых объяснений.
3. На одном составе сравнить текущие пять типов с альтернативами Помогает, Регулирует и «Используется для». Шесть типов повседневной колоды автоматически не переносить; определения сначала согласовать.
4. Считать уникальных соседей отдельно от числа типов/обоснований. Отдельно вывести прямые пары и прямые+контекстные; выделить карты с менее чем двумя прямыми соседями как кандидатов на разбор, не как автоматическое исключение.
5. После выбора значений и типов решать о заменах и собственном нейтральном наборе. Проверять минимум двух партнёров уже внутри итогового игрового состава после изъятия нейтральных.
6. Вероятности рук считать только по проверенному графу и явно заданным состояниям поля. Пока ни вероятностное отсечение, ни возрастная пригодность не установлены.

**Предварительный вывод:** средняя колода тематически связная, но значения не зафиксированы, а часть естественных отношений плохо выражается текущими типами. Данных пока недостаточно для честного списка «самых слабых» карт. Сначала устранить неоднозначность и сравнить типы, затем удалять слова.
