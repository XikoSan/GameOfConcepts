# Средняя колода: статус исследования

**Актуальный подход — `inductive-v1/`.** По уточнению пользователя типы должны выводиться из объяснений, а не задаваться заранее.

Файлы `cards.txt`, `relations.txt`, `audit.json`, `report.md` и скрипт `../tools/audit_medium.py` — остановленный дедуктивный черновик. Его шесть типов, исключения карт, нейтральный набор и вероятности НЕ являются рекомендацией или основанием для интеграции. В частности, отложенные там Власть, Конкуренция, Конфликт, Ответственность, Профессия, Религия и Репутация возвращаются в исходный пул исследования.

Начальный корпус нового этапа — реальные 40 карт средней колоды. Дополнительные 16 слов прошлого черновика пока не подмешиваются: они были выбраны под предположенные отношения. После изучения закономерностей можно расширить пул независимо от них.
