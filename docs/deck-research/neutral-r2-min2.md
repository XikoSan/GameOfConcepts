# Нейтральная колода R2: минимум два игровых партнёра

Заменяет предложение R1 для разделения 48 карт. Исходный набор `prototype48.json` остаётся без изменений. Проверка основана только на основных объяснениях: спорные связи и соседство с нейтральной картой не используются для выполнения минимума двух партнёров. Это исследовательский состав, не изменение приложения.

## Условие выполнено

**8 нейтральных + 40 игровых карт.** У каждой игровой карты от двух до семи разных партнёров среди остальных 39 игровых слов. Всего 63 игровые пары, все шесть типов отношений сохранены. Граф игровых карт связен. Каждая нейтральная карта имеет от пяти до десяти партнёров среди игровых.

Количество типов и количество разных партнёров не смешиваются: два отношения с одним словом дают только одного партнёра.

## Поиск и ограничения

Перебраны допустимые разделения с помощью поиска с распространением ограничений: восемь нейтральных, сорок игровых, минимум два игровых соседа у каждой оставшейся карты. Дополнительно сохранялась связность игрового графа. В отличие от R1 кандидаты не ограничивались лидерами по степени.

Проверка возможности иметь минимум семь, затем шесть игровых партнёров у каждой нейтральной карты не дала решений при этих условиях. Для минимума пять найдено 525 связных разделений; предел поиска не достигнут. Из них выбран вариант с наибольшим числом пар нейтральная—игровая, затем с наибольшим числом сохранённых игровых пар. При равенстве используется фиксированный порядок слов. Это оптимизация по указанным числовым предпочтениям в существующей разметке, не доказательство лучшего игрового опыта.

Проверены состав, отсутствие пересечений нейтрального и игрового наборов, все 40 степеней, связность и сохранение шести типов. Минимум два соседа не гарантирует наличие хода в любой руке или на любом поле: оба нужных слова могут не выпасть или быть недоступны геометрически.

Ранее предложенные «Аккуратность», «Внимание», «Знание», «Игра» и «Самостоятельность» теперь остаются игровыми, поскольку удалять все сильные слова без учёта их партнёров нельзя.
