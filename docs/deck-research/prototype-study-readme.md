# Исследование R1: материалы для проверки

- `six-relations-draft.md` — определения шести отношений, границы и спорные примеры.
- `prototype40.md` — компактный состав с выбранными значениями и объяснениями связей.
- `prototype-comparison.md` — сравнение 60, 48 и 40 карт, ограничения модели, составы альтернатив.
- `prototype60.md` — исходный тематический прототип и полный реестр его объяснений.
- `prototype60-simulation.md` — модель размещения, вероятность старта и диагностика сценариев.
- `cross-pool-r1.json` — новые объяснения; статус каждой строки сохранён, отклонённые строки не входят в граф.

Результат: рассмотрены 91 межсписочное объяснение, 90 сохранены как основные или условные. Проверка была направленной вокруг пробного состава, не исчерпывающей для всех 300 слов. 40 карт — компактный кандидат для первой практической проверки, 48 — более широкий смысловой вариант. Математически оптимальная колода не заявляется.

У сценариев отдельные личные колоды и руки игроков, ортогональное соседство, запрет одинаковых понятий по стороне и однократная пересдача. Голосование и стратегия по очкам отсутствуют. Нейтральный старт заменён явно обозначенными тестовыми центрами. Все вероятности относятся к этой модели и авторской разметке.

Для воспроизведения: tools/build_prototype60.py, tools/simulate_prototype60.py, tools/compare_prototypes.py (Python, только стандартная библиотека). Действующие правила, каталог и код приложения не изменены.
