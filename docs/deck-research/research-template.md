## 5. Наблюдения

Одна строка — предъявление или игровая ситуация. Анонимный код участника позволяет отличать повторные ответы одного человека от независимых наблюдений.

|---|---|---|---|---|---|---|---|---|---|---|

Результат: работает без справки / работает после сводки / не работает после сводки / недостаточно данных. Не заполнять вымышленными участниками и ответами.

## 6. Оценка критериев

Коды C01–C10 определены в инструкции. Использовать отдельную строку для каждого критерия: один общий балл запрещён без дополнительной методики.

| Карта / версия | Код критерия | Статус | Основание: R / O / W / источник | Экспертная оценка или наблюдение | Условия и противоречия | Что проверить дальше |
|---|---|---|---|---|---|---|
| C001 / 1 | C01 | | | | | |

Статус: подтверждено / работает при условии / обнаружена проблема / данных недостаточно.
