# Проверка критериев отбора и вероятностной модели

## Главный результат

Сводка относится только к известным связям трёх реестров. 300 названий уникальны. Между прежними пулами не размечались 30 000 возможных пар; внутрипуловая разметка тоже неполная. Поэтому отсутствие ребра означает отсутствие записи, а не доказанную невозможность связи.

В исходной разметке 94 слова имеют от двух до четырёх типов отношений. Если оставить только эти слова, 48 из них уже не сохраняют минимум двух типов. Повторное удаление даёт цепочку: 94 → 46 → 32 → 28 → 27 → 26. Это устойчивый остаток известного графа, а не рекомендуемая колода.

## Что требуется исправить

1. Различать минимум двух типов и верхнюю границу четыре. Верхняя граница исключает более универсальные слова без явной пользы; в текущей разметке она исключает «Тренировку» с пятью типами связей.
2. Типы и соседей считать внутри итоговой колоды, после всех исключений. Сохранять только богатые по типам слова может быть ошибкой: их партнёры с одним типом поддерживают граф.
3. Две категории — независимая смысловая разметка, а не переименование типа связи или возможность рассказать историю о слове. Старые категории были одиночными; вторичная принадлежность пока не проверена. Не объявлять критерий выполненным.
4. Формула без порога не является фильтром. Пользователь выбрал показывать вероятности для нескольких размеров поля, без отсечения.
5. Вероятность для конкретной карты и вероятность хода из руки — разные показатели.
6. Проверить пары между исходными списками, прежде чем оценивать их объединение как одну колоду.

## Формулы

Для фиксированного доступного поля B: P(ход | B) = 1 − C(M − K(B), 5) / C(M, 5). M — размер пула случайной руки, K(B) — число разных совместимых карт в этом пуле. При M < 5 нужна другая фактическая величина руки.

Для отдельного слова w и равномерно случайного поля из b других карт: P(слово совместимо с полем) = 1 − C(N − 1 − d(w), b) / C(N − 1, b). d(w) — число разных соседей слова, N — размер колоды. Эта формула не содержит размер руки: она отвечает на другой вопрос.

Вторая формула не описывает реальное разрастание поля: игроки выбирают карты, а не выкладывают равномерно случайные. В обеих моделях предполагается, что все выбранные карты поля доступны для размещения соседней карты. Реальные клетки, запреты размещения, нейтральные карты, дубликаты и распределение карт между игроками здесь не смоделированы.

Это контрольная модель, не прогноз партии: случайное поле, все карты доступны, рука равномерно выбирается из остальных 300 − b карт. Неразмеченные связи не используются; модель показывает обеспеченность только записанными связями.

## Что можно считать готовым результатом отбора

Нужна многокатегорийная разметка слов с обоснованиями, дополненная разметка межсписочных пар и пересчёт связности после отбора. Вероятности пока остаются диагностическими колонками, а не отметкой «прошёл». Итоговую колоду из одного устойчивого остатка строить преждевременно.
