# Источники встроенной справки «Эмоции и чувства»

Дата проверки: 13 ноября 2026 года. Область: все 57 игровых и 5 нейтральных карт текущего `emotionsCatalog.ts`.

Тексты в `src/data/glossaryEmotions.ts` — короткие оригинальные редакторские пояснения, составленные своими словами после сверки словарных значений. Они не являются цитатами, полными словарными статьями, перечнем допустимых игровых связей или определениями, ограничивающими решение участников. Дополнительные значения приведены выборочно, когда они помогают увидеть распространённую многозначность. Для эмоциональной колоды первым дано соответствующее ей значение; при этом другие значения слова не объявляются ошибочными.

## Как проверялись источники

Все 62 названия проверены через официальный [Action API Викисловаря](https://ru.wiktionary.org/w/api.php), `action=query`, `prop=revisions`, `rvprop=content`, `rvslots=main`, `redirects=1`. Для каждого названия прочитаны строки раздела «Значение». Примеры из литературы и перечни синонимов не подставлялись как определения; автоматический выбор первого результата поиска не использовался. Все названия имеют существующую страницу; «слёзы» перенаправляет на [«слеза»](https://ru.wiktionary.org/wiki/слеза).

Прямые ссылки для каждой карточки находятся в её поле `sources`. При отсутствии ё в пользовательском вводе выбор того же понятия должен обеспечиваться нормализацией приложения, а не поиском сторонней статьи.

### Отсылочные определения

Одной страницы существительного недостаточно для следующих пояснений. Дополнительно прочитаны:

- [бодрый](https://ru.wiktionary.org/wiki/бодрый) — для «Бодрость»;
- [увлечённый](https://ru.wiktionary.org/wiki/увлечённый) — для «Увлечённость»;
- [безутешный](https://ru.wiktionary.org/wiki/безутешный) — для «Безутешность»;
- [вялый](https://ru.wiktionary.org/wiki/вялый) — для «Вялость»;
- [приподнятый](https://ru.wiktionary.org/wiki/приподнятый) — для «Приподнятость»;
- [разбитый](https://ru.wiktionary.org/wiki/разбитый) — для «Разбитость»;
- [подавленный](https://ru.wiktionary.org/wiki/подавленный) и [подавить](https://ru.wiktionary.org/wiki/подавить) — для «Подавленность»;
- [нежный](https://ru.wiktionary.org/wiki/нежный) — для «Нежность»;
- [переживать](https://ru.wiktionary.org/wiki/переживать) — для повседневного значения «Переживание» как беспокойства.

### Многозначность

Особенно проверены [отношение](https://ru.wiktionary.org/wiki/отношение), [состояние](https://ru.wiktionary.org/wiki/состояние), [реакция](https://ru.wiktionary.org/wiki/реакция), [ощущение](https://ru.wiktionary.org/wiki/ощущение), [чувство](https://ru.wiktionary.org/wiki/чувство), [интерес](https://ru.wiktionary.org/wiki/интерес), [тревога](https://ru.wiktionary.org/wiki/тревога), [волнение](https://ru.wiktionary.org/wiki/волнение), [ласка](https://ru.wiktionary.org/wiki/ласка). Для «Ласка» прочитаны оба русских омонима: проявление нежного отношения и животное. Для «Состояние» отдельно сохранено значение имущества, для «Отношение» — общая связь, взаимодействие и математическое значение.

Для физических значений слова «Напряжение» дополнительно проверены вступления конкретных статей [«Электрическое напряжение»](https://ru.wikipedia.org/wiki/Электрическое_напряжение) и [«Механическое напряжение»](https://ru.wikipedia.org/wiki/Механическое_напряжение) через официальный Wikipedia API с `prop=extracts`, `exintro=1`, `explaintext=1`. Это ссылки на определённые понятия, не на страницу поиска.

## Границы проверки

Проверена осмысленность кратких пояснений и существование соответствующих страниц на указанную дату. Не утверждается, что приведены все переносные, профессиональные, устаревшие и региональные употребления. Отдельные слова различаются не жёсткими диагностическими границами; справка не назначает медицинские состояния и не используется как судья игрового обоснования. Внешние страницы могут меняться, встроенные тексты меняются только вместе с обновлением игры.

## Проверка состава

Каждый `definitionId` из текущих `EMOTIONS_PLAY_CARDS` и `EMOTIONS_NEUTRAL_CARDS` представлен ровно один раз. Названия и состав колоды не изменены. Для «Слёзы» добавлен поисковый вариант «слеза»; остальные варианты е/ё обрабатываются общей нормализацией.
