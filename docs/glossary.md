# Встроенная справка по понятиям

Обе доступные колоды и их нейтральные карты имеют локальные редакторские пояснения. Данные лежат в `src/data/glossaryEmotions.ts` и `src/data/glossaryDiscussion.ts`; источники проверок записаны рядом в `glossary-emotions-sources.md` и `glossary-discussion-sources.md`.

Карточка словаря привязана к стабильному `definitionId`. Для свободного поиска и старых сохранений есть точное сопоставление названия с нормализацией регистра, пробелов и ё/е; автоматического выбора приблизительного совпадения нет. Варианты названий допускаются только через явные aliases. Добавление карты требует отдельного определения и проверки покрытия тестом.

Тексты — краткие оригинальные пояснения для игры, а не копии статей или список правильных игровых связей. Существенные дополнительные значения показываются отдельно. Участники оценивают обоснования самостоятельно, справка не является автоматическим судьёй.

Справка загружается из приложения без сетевых запросов и работает в APK без интернета. Ссылки «Подробнее» ведут на конкретные проверенные страницы и требуют сети. Если свободный запрос отсутствует в словаре, игра сообщает об этом и предлагает ручной внешний поиск. Произвольная первая статья Wikipedia больше не подставляется.

Кнопка сообщения об ошибке открывает существующую текстовую форму обратной связи с названием понятия. Письмо отправляет сам игрок через своё почтовое приложение; автоматической отправки и нового почтового сервиса нет.
